# 第一阶段：网页可行性验证

这一阶段只验证分享链接、浏览器登录资料复用和评论加载。它是独立命令行程序，尚未接入 Tauri 界面，也不会导出评论正文。

## 运行环境

- Windows，已安装 Google Chrome。
- `pnpm install` 后可运行以下命令。
- 浏览器资料保存在 `%LOCALAPPDATA%\douyin-comment-scraper\phase1-chrome-profile`，不在仓库中。这里可能包含登录 Cookie，请勿复制或提交。

## 命令

解析分享文案并观察页面评论加载（默认打开可见的 Chrome）：

```powershell
pnpm phase1:probe '<抖音分享文案或视频链接>'
```

无人操作的检查可以加 `--headless`；`--scrolls 3`、`--replies 1` 和 `--wait-ms 1800` 可调整滚动次数、展开回复次数与每次等待时间。报告写入 `.phase1/last-report.json`，只包含链接、计数和加载状态，不包含 Cookie 或评论正文。

首次登录：

```powershell
pnpm phase1:probe --login '<抖音视频链接>'
```

在打开的 Chrome 中自行登录，回到终端按 Enter。命令会刷新页面，写出 `.phase1/login-report.json`。之后再次运行普通 `phase1:probe`，检查 `loginPromptVisible` 是否变为 `false`，并对比实际加载量。登录过期后需要再次登录；现阶段只用页面提示文字作为登录状态的验证信号。`domCommentItems` 包含已展开的回复，顶层评论和回复的 ID 数分别见 `capturedCommentIds`、`capturedReplyIds`。

运行链接解析及浏览器资料复用测试：`pnpm phase1:test`。资料复用测试在本地测试网页上验证 Cookie 与 localStorage 能跨浏览器重启保留；它不代替抖音实际登录验证。

## 已完成的实测

2026-10-08 使用用户提供的分享文案进行匿名检查：

- 提取出用户提供的短链，跳转到视频 `7693918682930819557`。
- 视频页加载成功，标题为“今天怎么看强者们#福彩3D - 抖音”。
- 页面加载了两批评论，各 5 条；浏览器响应中识别到 10 个不同评论 ID，正文均非空。
- 页面仍提示登录；当时页面显示的评论总数约为 1700，浏览器响应标记还有更多评论。数值会随着新评论变化。
- 匿名状态下点击“展开回复”会触发网页请求，但本次响应正文为空；回复是否可加载需在登录后复测。
- 本地浏览器资料复用测试已通过：带有效期的 Cookie 和 localStorage 在关闭并重新启动 Chrome 后仍可读取。抖音实际登录凭证是否继续有效，取决于平台会话规则，仍需扫码实测。
- 用户扫码登录后，关闭浏览器并再次运行检查，页面不再显示评论登录提示；连续滚动 8 次，实际观察到 75 个不同评论 ID。网页当时报告约 1760 条评论，仍有更多内容。
- 已登录后点击“展开回复”，网页返回 3 条回复并更新了页面评论区域；后续回复仍可继续加载。

## 判定边界

脚本只观察抖音网页自行发出的评论响应，不主动请求内部接口。网页结构、响应字段和登录规则都可能变化。`capturedCommentIds` 是本次实际观察到的数量，`reportedTotal` 是网页返回的数量；两者不能据此推断“已提取全部评论”。验证码或访问限制需要用户自行处理。
